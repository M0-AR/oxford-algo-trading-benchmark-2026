CEO summary (30 seconds)

1. Buy-and-hold beat every robot on total profit 2015–2026 — but suffered the deepest crashes. 2. Robots cut the pain (smaller drawdowns) yet gave up return — safety has a price. 3. Breakout trend-following was the best robot on Bitcoin (Sharpe 1.11); mean-reversion failed on crypto. 4. One in four time-windows flips sign — past winners regularly become losers, so walk-forward checks are mandatory. 5. A simple AI predictor scored ~51–57% (coin-flip) — proof that validation matters more than clever signals.

Bottom line for decision-makers: use this repo as a lie detector before trusting any backtest, fund pitch, or “90% win-rate” screenshot.

Explain it like I am five (even a donkey gets it)

🐢 Trend robot (SMA)

“If the recent average price is above the old average, buy; else wait.” Catches waves, late to turn.

🙃 Bounce robot (RSI)

“If it fell too fast, buy the dip; if it pumped too fast, sit out.” Works sideways, dies in rockets.

🌊 Breakout robot (Donchian)

“If price hits a 20-day high, ride; if it hits a 10-day low, hide.” Best Bitcoin robot here.

🪨 Buy-and-hold rock

“Buy once, never sell.” Wins marathons, endures nightmares (−83% on Bitcoin).

FAQ (asked by real humans)

Does it trade live / spend money?No. Research-only. It reads free public prices and writes pictures + JSON. No broker keys, no orders.
Why did buy-and-hold win? Are robots useless?BH wins return in a 2015–2026 mega-bull; robots win sleep (smaller drawdowns). Pick your pain. The repo quantifies the trade.
Why is RSI terrible on Bitcoin?Trending + fat-tailed markets punish dip-buying. The table proves it: RSI Sharpe 0.42–0.52 vs trend 0.88–1.11. Gate it by volatility or skip crypto.
What does “DSR = 1.00 everywhere” mean?Honestly: our K=7 trial count is too small, so significance saturates. It is a warning light, not a trophy. Fix = K≥100 sweep-as-trials (roadmapped).
Can I use other symbols / dates / costs?Yes: --symbols AAPL,MSFT,ETH-USD --start 2020-01-01 --cost_bps 20. Sources + bars are recorded in JSON.
Offline / no internet?It reuses data/*.csv cache, else clearly-labelled synthetic data. Synthetic rows say "source":"synthetic" — never mixed silently.

Troubleshooting (3-minute fixes)

① yfinance empty / 429 → wait 60 s, rerun; Stooq is tried first automatically.
② pip “externally managed” → use pip install --break-system-packages -r requirements.txt or Docker.
③ video will not play → use the GIF right beside it; both are <1 MB.
④ Docker build slow → first pull of python:3.12-slim takes minutes once, then cached.
⑤ Numbers drifted a little on rerun → normal: Yahoo revises history; JSON stamps dates + bars for audit.
